SAFEDRIVE ONE website
=====================

Photos: all images are AI-generated with Google Gemini and saved in the "images" folder.
To change a photo, replace the file in "images" with a new one using the SAME file name.

Video: save your 30-second AI video (with audio) as  video/safedrive-ad.mp4
When it is there, the Home page plays it instead of the storyboard.

To put the site online for free: upload this whole folder to Netlify Drop
(app.netlify.com/drop) or GitHub Pages, then use that link in your submission.
